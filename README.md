# منظومة دلالة للمطاعم والمقاهي — Dalala Restaurant & Cafe

نقطة بيع حديثة للمطاعم والمقاهي: **صالة وطاولات، سفري (تيك أواي)، توصيل، طلبات المطبخ، ورديات الكاشير، المصروفات والتقارير** — بواجهة عربية، وتعمل بدون إنترنت على ويندوز أو المتصفح.

A modern point of sale for restaurants and cafés: dine-in tables, takeaway, delivery, kitchen orders, cashier shifts, expenses and reports. Works offline on Windows or in the browser.

## التشغيل — Getting started

- **ويندوز:** شغّل `Dalala-Restaurant-Setup-<version>.exe` (يُبنى تلقائياً عبر GitHub Actions، أو محلياً — انظر أدناه).
- **المتصفح:** افتح `index.html` مباشرة (ملف واحد مستقل بخطوطه وأيقوناته).

| المستخدم | الرمز (PIN) |
|---|---|
| المدير | `1234` |
| كاشير | `0000` |

> غيّر الرموز من **الإعدادات ← المستخدمون** قبل الاستخدام الفعلي.

## الوحدات — Modules

- **أنواع الطلب:** صالة (طاولات حسب المنطقة: صالة، تراس…)، سفري، توصيل مع رسوم التوصيل وبيانات الزبون، بيع فوري.
- **الطاولات:** حالة كل طاولة (متاحة / مشغولة)، إضافة طاولات ومناطق.
- **المطبخ:** إرسال الأصناف للمطبخ، مع حماية تقليل الأصناف المرسلة.
- **الدفع:** نقدي أو بطاقة، الخصم، الضريبة، الخدمة، حساب الباقي، طباعة الفاتورة وإعادة طباعتها.
- **الورديات:** فتح وإغلاق الوردية برصيد افتتاحي، ملخص المبيعات النقدية والبطاقة والفرق، سجل الورديات.
- **القائمة:** أقسام (مشروبات ساخنة وباردة، سندويتشات، بيتزا، وجبات، حلويات…) وأصناف بالأسعار والتكلفة والمخزون.
- **الفواتير:** سجل الفواتير، الإلغاء والإرجاع، التصدير.
- **المصروفات والتقارير:** إجمالي المبيعات، الخصومات، متوسط الفاتورة، صافي الربح التقديري، سجل العمليات.
- **المستخدمون:** مدير وكاشير برمز PIN.

## التشغيل على عدة أجهزة — Several devices, one database

- **الجهاز الرئيسي** (عادةً جهاز الكاشير): الإعدادات ← «التشغيل على عدة أجهزة» ← جهاز رئيسي ← حفظ وإعادة التشغيل. يظهر عنوان الجهاز (IP) و**مفتاح الربط**. عند أول تشغيل يطلب ويندوز السماح بالشبكة — اختر «الشبكات الخاصة» ثم «سماح».
- **كل جهاز فرعي** (تابلت النادل، شاشة المطبخ، كاشير ثانٍ): الإعدادات ← جهاز فرعي ← أدخل العنوان ومفتاح الربط ← اختبار الاتصال ← حفظ وإعادة التشغيل.
- الطلبات المفتوحة على الطاولات، تذاكر المطبخ، الفواتير، المخزون، الأصناف والإعدادات تظهر على كل الأجهزة خلال أقل من ثانية.
- أرقام الفواتير وأرقام الطلبات اليومية لا تتكرر حتى لو حفظ جهازان في نفس اللحظة (يوحّدها الجهاز الرئيسي، وتتبعها تذاكر المطبخ). المخزون يُخصم من كل الأجهزة دون أن تضيع عملية.
- إذا انقطعت الشبكة يواصل الجهاز الفرعي العمل وتُرسل العمليات تلقائياً عند عودة الاتصال.
- قاعدة البيانات المشتركة: `%APPDATA%\Dalala Restaurant\shared\shared-db.json` على الجهاز الرئيسي مع نسخة احتياطية يومية (آخر 30 يوماً). المنفذ الافتراضي 47630 (TCP). كل جهاز يحتاج مفتاح تفعيل خاص به.

## بناء مثبّت ويندوز — Building the Windows installer

```bash
cd desktop
npm install
npm run dist          # على Linux/macOS بدون Wine → dist/Dalala-Restaurant-Setup-<version>.exe
npm start             # تشغيل نسخة سطح المكتب للتجربة
```

البيانات تُحفظ على الجهاز (في نسخة ويندوز داخل `%APPDATA%\Dalala Restaurant`). يعمل هذا الإصدار على جهاز واحد؛ لعدة أجهزة (كاشير + مطبخ على شاشات مختلفة) يلزم خادم مركزي.
